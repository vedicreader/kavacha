icons

Make the macOS, Windows and web icons an app needs from one square image

An app needs its icon in several formats: an .icns file for a macOS bundle, an .ico file for Windows, and a small PNG favicon for the web page in the window. This module makes all of them from one square image. It needs Pillow, which the icons extra installs. Most callers only need icons_for, at the end of the page.

An .icns file is built from a folder of PNG files with fixed names, which macOS’s iconutil tool reads. ICNS_SIZES lists the ten names and the pixel size of each. The @2x names are double-size copies for Retina screens, so some sizes appear twice and there are seven distinct sizes. ICO_SIZES are the sizes ico puts in a Windows icon by default.

ICNS_SIZES[:4]
((16, 'icon_16x16'),
 (32, 'icon_16x16@2x'),
 (32, 'icon_32x32'),
 (64, 'icon_32x32@2x'))

_open loads the source image as RGBA and checks it. An app icon has to be square and at least 512 pixels wide. macOS draws icons at up to 1024 pixels, and a smaller source would be scaled up and look blurred, so it is refused instead. Any format Pillow can read works; the example opens a JPEG.

_open(root/'logo.jpg').mode, _open(root/'logo.jpg').size
('RGBA', (1024, 1024))

These are the two errors you get for a source that is not square or is too small. The examples work in a temporary folder, shown here as /proj.

Image.new('RGBA', (800, 400)).save(root/'wide.png')
for p in ('wide.png', 'small.png'):
    try: _open(root/p)
    except ValueError as e: print(str(e).replace(str(root), '/proj'))
/proj/wide.png is 800x400; an app icon has to be square
/proj/small.png is 128px; macOS draws icons at 1024 and will upscale this

iconset

def iconset(
    src, out
):

The .iconset folder iconutil turns into an .icns. Returns the folder.

iconset writes the ten PNG files into the folder out and returns it. icns builds the .icns file out from them with iconutil, then deletes the PNG folder unless keep_iconset is set. iconutil only exists on macOS, so elsewhere icns raises a RuntimeError, as the second example shows. The folder is deleted either way.

out = iconset(logo, root/'Set.iconset')
sorted((Image.open(p).size[0], p.stem) for p in out.glob('*.png'))

ico

def ico(
    src, out, sizes:tuple=(16, 24, 32, 48, 64, 128, 256)
):

A Windows .ico from one square image. Pillow writes every size into the one file.

ico writes one Windows .ico file that holds the image at each size in sizes. A size above 256 pixels, the largest an .ico can hold, is left out, which is why the second example asks for 512 and gets only 16 and 32.

with Image.open(ico(logo, root/'assets'/'Demo.ico')) as im: print(sorted(im.info['sizes']))
with Image.open(ico(logo, root/'small.ico', sizes=(16, 32, 512))) as im: print(sorted(im.info['sizes']))
[(16, 16), (24, 24), (32, 32), (48, 48), (64, 64), (128, 128), (256, 256)]
[(16, 16), (32, 32)]

favicon

def favicon(
    src, out, size:int=64
):

Write a PNG favicon for the web UI.

favicon writes a PNG size pixels wide, 64 by default, for the web page. icons_for writes every icon a bundle needs into the folder assets: favicon.png, <name>.ico and, on macOS, <name>.icns. It returns their paths by kind. Run it when you set up a project or change the logo, then point App(icon=...) at the result. The saved output came from a machine that is not a Mac, so it has no icns.

made = icons_for(logo, root/'assets', 'Demo')
{k: Path(v).name for k, v in made.items()}
{'favicon': 'favicon.png', 'ico': 'Demo.ico'}
